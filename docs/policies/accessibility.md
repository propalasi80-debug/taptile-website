**The short version:** we want everyone to be able to use trytaptile.com. We aim
to meet the **Web Content Accessibility Guidelines (WCAG) 2.2 at level AA**.
If something on the site doesn't work for you, email **support@trytaptile.com**
and we'll help you another way and fix it.

## What we've done

- Every page can be used with a keyboard alone, with a visible focus outline and
  a "Skip to content" link.
- Text and controls meet WCAG contrast requirements.
- Form fields have labels, and errors are announced to screen readers.
- Images that carry meaning have text descriptions.
- If your device is set to reduce motion, the site's animations are turned off.
- Pages work at phone width and when zoomed to 200%.

## What we know isn't there yet

- **The configurator** needs a Chromium-based browser (Chrome, Edge, Opera,
  Arc) because it uses WebHID to talk to the keyboard. It hasn't yet been
  tested with screen readers. [FILL IN: remove this line or update it once the
  configurator is on the site and tested.]
- **The product itself** is a physical keypad. Every key and both dials can be
  remapped, which can help people who use alternative input setups, but we
  haven't tested it with assistive-technology users and don't claim it's
  designed for them.
