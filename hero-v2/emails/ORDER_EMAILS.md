# Order emails (Hero v2 launch)

How it works with a Stripe Payment Link and no backend (D49):
1. **Instant receipt:** Stripe Dashboard → Settings → Customer emails → turn on "Successful payments". Stripe emails the buyer a receipt the moment they pay.
2. **After payment:** in the Payment Link settings, set "After payment" → "Don't show confirmation page" → redirect to `https://trytaptile.com/thanks`.
3. **Order confirmation from us:** send the email below from support@trytaptile.com within 1 working day of each order (20 orders, copy and paste). It confirms the order, which is when the sale is accepted (terms §3).

These are transactional emails confirming a purchase the buyer asked for, so they are not marketing under the Unsolicited Electronic Messages Act 2007 (DIA). Do not add promotions to them.
